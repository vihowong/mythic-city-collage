# 决策规则速查 — kiuzyx current visual corpus

| 能力 | 一句话规则 |
|---|---|
| 从需求生成去符号化视觉命题 | 先定义色彩面积、邻接和表面张力，再选择场景。 |
| 选择构图骨架与主轮廓 | 先选安静正交场域或极繁全景，再固定主结构。 |
| 编排承重—过渡—事件—停顿色调 | 用大面积深色、暖中性停顿、少量朱红事件和三组邻接关系组织色场。 |
| 装配舞台式不可能空间 | 用正交墙线、窗框和低密负形建立可读舞台。 |
| 规划细节岛与密度地形 | 先留大面积负形，再把细节集中在二至四个岛。 |
| 统一印刷表面并控制材质断点 | 清晰边缘 + 三种尺度微颗粒 + 哑光低高光，构成图像复制质感。 |
| 将视觉语法编译成生成提示词 | 先写色块、邻接、明度和微颗粒，再写构图与场景。 |
| 按上游优先顺序诊断与修复 | 先查色彩面积/邻接，再查主形、明度、纹理和场景承载。 |
| 锁定系列连续性的视觉表面 | 固定色角色、邻接、暗部和微颗粒，每张只改变结构与细节岛。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
