# 决策规则速查 — Mythic City Collage visual corpus

| 能力 | 一句话规则 |
|---|---|
| 从需求生成去符号化视觉命题 | 先把主题翻成可用形式验证的张力，再决定放什么。 |
| 选择构图骨架与主轮廓 | 每张图只选一个主骨架，并保留一个缩略图可读的主形或轴线。 |
| 编排承重—过渡—事件—停顿色调 | 按面积和职责分配颜色，不按色相数量堆叠。 |
| 装配舞台式不可能空间 | 入口、层次和观看锚点必须让不可能透视仍然可读。 |
| 规划细节岛与密度地形 | 把高密信息收成二至四个细节岛，并保留低密承重区。 |
| 统一印刷表面并控制材质断点 | 一个连续印刷表面，一个承担语义的主导材质断点。 |
| 将视觉语法编译成生成提示词 | 先编译构图、色调、密度和材质，再把形象放进提示词。 |
| 按上游优先顺序诊断与修复 | 先查主轮廓，再查灰度、细节和材质；只修第一个失败层。 |
| 锁定系列连续性的视觉表面 | 固定视觉表面和色板，每张只推进一个空间职责。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
