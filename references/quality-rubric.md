# 质量评分与修复

先按交付媒介评分。只有达到通过线，并确认没有零分项，才视为可交付。

## 静态作品

每项 0–2 分，共 7 项、满分 14 分。建议通过线为 11 分，且不能有 0 分。

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 日常锚点 | 城市空泛或无法辨认 | 有普通物件但不参与叙事 | 具体物件把异象钉在可居住的世界 |
| 异象动作 | 只是贴图或堆料 | 有异常但空间不响应 | 异常改变尺度、空间、身份或倒影 |
| 注意力轴 | 多焦点、无方向 | 有方向但被细节打断 | 一条清楚轴线连接人物与异象 |
| 材质触感 | 光滑统一 3D | 有一点颗粒但无层级 | 线稿、平涂、纸噪和硬边碰撞有语义 |
| 色彩控制 | 色彩平均或脏灰 | 有冷暖但没有主次 | 冷底、事件色、中性停顿色比例明确 |
| 观看关系 | 人物英雄化或不存在 | 人物可辨但不承载观看 | 人物让观众共享“看见异象”的瞬间 |
| 细节秩序 | 元素随机或缺乏信息 | 细节丰富但远近层级不稳 | 远看清楚、近看有文化层和材料变化 |

## 动态作品

每项 0–2 分，共 8 项、满分 16 分。建议通过线为 13 分，且不能有 0 分。

先完成上方七项中与画面有关的判断，再增加：

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 运动动机 | 无意义环绕或持续 morph | 有运动但镜头与事件关系弱 | 每个运动都服务于发现、推进或撤回 |
| 时间结构 | 异象过早或过晚，没有停顿 | 有阶段但节奏拥挤 | 观察、侵入、响应、停顿、撤回清楚 |

## 快速修复表

| 症状 | 首选修复 |
| --- | --- |
| 像普通赛博朋克 | 删除霓虹堆料，加一个便利店、住宅墙或湿路面 |
| 太满、看不出重点 | 保留一个主导异象，把其他异常缩成背景纹样 |
| 梦境太飘 | 增加具体地面材质、人物动作和可解释的光向 |
| 太像 3D 游戏 | 加线稿、套色偏移、硬边拼贴、纸噪，减少光滑折射 |
| 没有故事 | 建立“人物—门槛—异象”关系，让异象执行一个动作 |
| 构图像元素仓库 | 选一条中心轴，移走不服务轴线的物件 |
| 人物没有存在感 | 缩小人物并让他停下、仰望、低头或看手机 |
| 视频不连贯 | 锁定镜头、角色与天空逻辑，只保留一次显形 |
| 视频一直变形 | 将 morph 改为光、云、雾、倒影或影子的局部变化 |
| 声音过度解释 | 去掉旁白和高频提示音，只保留环境声与低频压力 |

## 最终三问

1. 这是发生在**一个真实地方**的异象，还是一张没有任何生活痕迹的幻想壁纸？
2. 异象是否**做了一件事**，而不只是被放在画面里？
3. 观众是否先看到人物，再被人物的视线带到不可能之处？

三个答案都清楚，再交付。
