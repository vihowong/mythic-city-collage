# R — 视觉证据

> 43 张图在人物、面孔、山水、城市与抽象构图之间切换，仍可由尺度压迫、观看、秩序冲突或空间穿透维持统一风格，并不依赖同一组象征物。

来源：`mythic-city-visual-corpus`，联系表 1–4；阶段 0 跨样本综合。

## I — 方法论骨架

先把需求压缩成一条视觉命题，再寻找具体载体。命题应同时包含两种力量或状态，例如“稳定秩序与不可见失控”“观看与被观看”“日常表面与深层宇宙”。这条命题必须能在删除所有象征物名称后仍然成立。

命题不规定题材，而规定观众应当先体验什么关系。之后选择构图骨架、色调和细节岛时，都以此命题作为取舍标准。若一个元素只能让题材更“神话”，却不能改变尺度、遮挡、观看或空间关系，它就不应进入主视觉。

## A1 — 应用示例

**类型：合成演练**。原图像素语料没有作者文字的命题，本演练用已验证规则展示执行方式。

- 输入：为一张关于“算法悄然接管日常生活”的音乐封面设计视觉。
- 执行：不直接列服务器、眼睛、电路和城市。将张力写成“熟悉的日常生活表面与不可见的控制层同时存在”；形式关系选择遮盖、尺度断层和局部泄露。
- 输出：一个普通房间保持完整轮廓，墙面的一小块材料尺度被替换成无限深的规则空间，人物保持停顿观看。
- 结果：未生成图，只验证命题可以脱离赛博符号成立。

另一个直接视觉案例是 `HW-7eK-a4AAv6y7.jpg`：大面积天空与横向悬浮人物建立“平静空间中的身体异常”，画面并没有依赖城市道具解释主题。

## A2 — 触发场景

1. 用户给出一个很抽象的主题、情绪或品牌关键词，不知道画面该长什么样。
2. 用户的需求只是元素列表，例如“龙、眼睛、城市、棋盘都要有”。
3. 用户要求某种风格海报，但现有方案只是素材堆叠，没有一句话能说清画面矛盾。

语言信号：

- “帮我做一个有氛围的概念”
- “我想要高级、超现实、迷幻，但不知道该放什么”
- “把这些元素融合起来”
- “turn this theme into a visual system”
- “concept art brief from this idea”

与相邻能力的区分：本卡只负责找到视觉命题；具体空间、色调和提示词分别交给后续能力。

## E — 可执行步骤

**必需输入**：主题、用途、目标观众/情绪。缺少主题时先提出 2–3 个不同方向；缺少用途时可以按海报默认，但需说明假设。

**交付物**：一句话视觉命题、2–3 条形式关系、一个去名词复述。

1. 从需求中提取两个可冲突的力量，例如“秩序/失控”“日常/宇宙”“观看/被吞没”。
   - 完成标准：两者不是同义词，也不是简单好/坏。
2. 指定能承载冲突的形式关系：尺度差、遮挡、倒置、复制、封闭、观看或穿透。
   - 完成标准：每条关系都能在缩略图中被判断。
3. 删除所有具体对象名称后重述命题。
   - 完成标准：原主题仍可识别，且不需要靠固定符号解释。
4. 若用户给出元素清单，把每个元素标为“承重主体、观看尺度、门槛、事件色、秩序边缘”之一。
   - 判停条件：无法分配职责的元素不进入主视觉。

## B — 边界

- 纯信息整理、产品参数页或已有严格品牌规范时，不要用它替代信息架构。
- 真实旅行摄影、普通叙事插画或要求严格写实空间时，不要强行制造不可能关系。
- 不把命题写得像论文段落；如果一句话不能转成构图判断，重新压缩。
- 不从具体作品推断作者意图，也不把“命题由我推导”写成作者原意。
- 用户已经提供完整且有效的视觉命题时，不要重写；直接进入构图骨架能力。
