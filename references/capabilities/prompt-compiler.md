# R — 视觉证据

> 27 个近期作品的题材覆盖电梯、卧室、商店、道路和全景城市，但持续共享深色大场、暖中性停顿、朱红事件、硬边结构、多尺度颗粒和低高光；风格不依赖固定物体。

来源：`kiuzyx-current-20261116` 跨样本综合。

## I — 方法论骨架

提示词应是设计决策的编译结果。顺序固定为：交付画幅 → 色彩—质感命题 → 色彩面积与邻接 → 构图模式/正交结构 → 明度与高光 → 多尺度纹理 → 负形和细节岛 → 具体场景与人物 → 负面约束。

场景与人物放在后半段，只负责执行已经确定的色彩、结构和表面职责。负面约束应针对当前最容易漂移的关系，例如平均彩虹、光滑三维、单层噪点、全图均匀细节与过亮黑场。

## A1 — 应用示例

**类型：合成演练**。原图为视觉证据，未提供作者提示词。

- 输入：音乐封面，主题“冷静仪式下的失控”，禁止直接使用龙或眼睛。
- 执行：选择正面祭坛骨架；深钴蓝承重，墨黑轮廓，米白停顿，朱红只做一个事件色；两处细节岛；一个镜面金属断点。
- 输出：提示词明确中心主轮廓、外围秩序、色面积、颗粒与断点，不靠“复古迷幻”标签。
- 结果：未调用生成器，只确认提示词具备可检查字段。

## A2 — 触发场景

1. 用户要求“直接给提示词”“生成图但不能像普通赛博朋克”。
2. 已有参考风格，需要把它编译成具体生成指令。
3. 生成结果总是元素堆叠，需要重写提示词结构。

语言信号：

- “给我可直接用的提示词”
- “英文 image prompt”
- “照着这个风格生成”
- “prompt for this art direction”
- “make the prompt less generic”

与相邻能力的区分：本卡不先决定风格；它编译前面已经选定的命题、骨架、色调、密度与材质。

## E — 可执行步骤

**必需输入**：视觉命题、画幅/用途、允许的载体与禁止项。若前六项决策缺失，先补齐或标为默认选择。

**交付物**：可直接使用的主提示词、负面约束、变量槽、关键决策说明。

1. 写交付规格与视觉命题。
   - 完成标准：删除名词后仍可理解目标。
2. 写构图骨架、主轮廓、入口和空间层级。
   - 完成标准：缩略图检查标准已包含。
3. 写色调职责与明度范围。
   - 完成标准：至少包含承重、事件、停顿三类。
4. 写细节岛与文字策略。
   - 完成标准：可数、可定位。
5. 写基础印刷表面、一个主导材质断点和统一方式。
   - 判停条件：不允许每个素材拥有独立渲染说明。
6. 最后写具体形象与动作。
   - 完成标准：每个形象都能对应前文的视觉职责。
7. 负面约束只覆盖本次高风险漂移，如多焦点、彩虹化、全图噪声、塑料三维。

## B — 边界

- 用户只要创意分析、不要生成提示词时不输出冗长 prompt。
- 生成器有固定长度上限时压缩措辞，不只保留风格标签。
- 不假装某种提示词能保证跨模型完全一致；生成结果仍需验收。
- 不把“著名艺术家风格”当成唯一提示，不复制具体作品构图。
- 图像生成工具不可用时，先交付提示词并明确没有实际生成。
