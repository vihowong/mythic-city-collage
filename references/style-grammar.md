# 视觉语法

## 素材读数

这套视觉来自 43 张竖幅静态作品与 2 段动态研究的共同规律，不是对某一帧的逐字复制。

- 静态作品多为 2:3、3:4 或接近 9:16 的竖幅，强调向上仰望和纵向旅程。
- 动态研究之一是约 32 秒、16:9 的多场景漫游，由 5 个约 5 秒的场景组成；另一段是约 20 秒、9:16 的单镜头显灵，异象在中后段占据天空。
- 作品反复使用蓝色天空、红橙云霞、黑白宇宙、米白云层、苔绿山林、朱红建筑和金色装饰边框。
- 可迁移的是构图、象征、材质与节奏；不要推断或宣称素材作者、出处或未观察到的创作过程。

## 核心命题

现代城市不是异象的反面，而是一层很薄的现代外壳。街道、便利店、住宅、窗户和水洼都可能泄露更古老的神话、图像记忆或被网络化的身体。

让“局部真实”和“整体不可能”同时成立：单看每个物体都有材质与体积，合在一起却违反尺度、重力、透视或自然规律。

## 五层空间

1. **日常地面。** 垃圾桶、自动售货机、卷帘门、路牌、便利店、空调外机、护栏、积水。必须具体、廉价、可触摸。
2. **观察者。** 黑大衣、白衬衫、无脸轮廓或小比例人物。人物负责提供尺度与视角，不负责解释画面。
3. **门槛。** 棋盘、台阶、红毯、道路、门洞、窗口、水洼或隧道。它把视线从“这里”送到“那里”。
4. **文明沉积层。** 东京塔、古典柱廊、鸟居、寺庙、山体、住宅与工业城同时存在，像时间被压平。
5. **异象层。** 巨龙、鬼面、巨日、眼睛、旋涡、光体、身体解剖或数据屏幕。一个异常要足够大，其他异常只做回响。

边框是可选的第六层。装饰花纹、经卷式边框、窗框或画框会把作品变成“被保存下来的神启”，同时为超高密度边缘提供秩序。

## 六条稳定规律

### 1. 轴线先于元素

最有效的构图通常是：

`观察者（下） → 门槛/道路（中） → 异象（上） → 宇宙或边框（最上）`

横向视频则把这条轴折叠成空间漫游：门、窗、街角或电线杆持续引导镜头，从一个现实表面进入下一个。

### 2. 碰撞，而非融合

版画线条、硬边摄影剪贴、3D 解剖和像素界面可以共处，但不要统一成同一种渲染风格。保留以下差异：

- 轮廓线粗细不同；
- 光源方向不完全一致；
- 透视灭点发生偏移；
- 照片边缘和纸张边缘可见；
- 数字材料保留压缩和错位。

### 3. 尺度就是情节

同一物件从装饰变成事件，主要靠尺度改变：红日从徽记变成天体，面具从配饰变成脸部，眼睛从屏幕符号变成天空，人物从主体变成文明前的尘埃。

### 4. 让冷底承载无限，让暖色制造事件

蓝色负责空间深度、夜晚与记忆；朱红负责时刻、危险、欲望与“现在”。米白云层和黑色宇宙负责停顿。绿色不是背景色，而是古老世界的湿度与生命。

### 5. 人必须处在“看见”而非“征服”的位置

人物通常背对镜头、停下脚步、低头看手机、吸烟或静立。不要让他们做出过度英雄化动作。观众要与人物共享同一个发现瞬间。

### 6. 平视与俯瞰可以故意冲突

前景台阶可能向上仰望，城市却像沙盘一样被俯瞰，巨物又悬在正上方。保留这种不可能透视，但始终用中心线、框边或颜色将画面重新钉住。

## 色彩系统

以下是可复用的近似色角色，不要求逐像素匹配：

| 角色 | 参考色 | 建议面积 | 用途 |
| --- | --- | --- | --- |
| 深钴蓝 | `#0B4EA2` | 25–45% | 天空、门洞、无限空间 |
| 朱砂红 | `#E4472B` | 8–18% | 太阳、道路、危险、建筑节点 |
| 墨黑 | `#07100D` | 15–30% | 宇宙、轮廓、人物和边框 |
| 云象牙 | `#E8D1AE` | 15–30% | 云、纸面、皮肤高光、神像 |
| 苔藓绿 | `#315538` | 8–22% | 山林、屋顶、生命层 |
| 旧金 | `#B28A45` | 0–6% | 边框、法器、神圣等级 |
| 肉桃色 | `#F0BEA8` | 3–12% | 人体、面孔、亲密感 |
| 电子青 | `#6EA3D2` | 0–8% | 屏幕、数据、记忆残像 |

避免让所有颜色平均出现。一张图通常需要一个压倒性的底色、一个瞬间色和一个中性停顿色。

## 材质语言

- **精细轮廓：** 建筑、衣褶、龙鳞和人物边缘用近似铜版画或漫画线稿的清晰勾线。
- **平涂块面：** 大面积颜色近似丝网印刷、木版画或老式海报，不追求写实渐变。
- **套色偏移：** 红、青或黑色边缘轻微错开，形成旧印刷感。
- **半调与纸噪：** 皮肤、云和天空可出现均匀网点、纤维纹理或轻微褪色。
- **硬边剪贴：** 材料替换处保持清楚轮廓，让“贴上去”成为视觉语法。
- **低清动态：** 视频可以有柔边、压缩块、扫描线与轻微帧抖动，但主体仍要清楚。

不要用高光塑料、景深虚化、无缝 CGI 或干净到没有触感的 3D 替代这些材质。

## 符号词典

符号不是固定答案，但它们在这套视觉中有稳定倾向：

| 符号 | 可执行的作用 |
| --- | --- |
| 富士山或远山 | 不变的圣地、记忆坐标、画面尺度锚 |
| 红日、黑日、月牙 | 宣布时刻、形成注视、标记入口 |
| 龙 | 守护通道、吞吐城市、把天空变成力量 |
| 鬼面 | 揭露社会身份的兽性、交换人格、婚礼/商务中的禁忌 |
| 眼睛 | 监控、觉醒、媒介化观看、太阳的替代物 |
| 棋盘与无限台阶 | 不可逃逸的秩序、选择、朝圣、算法路径 |
| 门洞、窗、镜框 | 折叠空间、保存另一世界、建立“画中有画” |
| 水洼与河 | 泄露倒影里的真相，把地面变成入口 |
| 鸟居、寺庙、希腊柱廊 | 文明层叠、朝圣、帝国与神话的共同记忆 |
| 便利店、招牌、电线 | 把神话固定在当代生活中，禁止漂浮成抽象梦境 |
| 解剖人体、屏幕、像素 | 身体被媒介化、网络成为新的器官 |
| 花束与礼服 | 礼俗表面下被压住的暴力或欲望 |

选择符号后，用一句话写出它的“职责”。写不出职责的符号应删除或降为背景纹样。

## 模式配方

### 神话全景

- 竖幅，前景占 20–30%，中景占 30–40%，异常与天空占 30–50%。
- 人物底部居中或略偏，红毯/棋盘/山路形成明确透视。
- 两侧可用山林、寺庙、古建和云层包住中央通道。
- 顶部放一枚主导天体，龙或面具只作为第二级异常。

### 日常显灵

- 选择一个普通街角、住宅外墙、便利店、停车位或湿路。
- 先用正常光色画出可居住的空间，再替换天空、倒影或远景山体。
- 异常进入后，地面必须有响应：影子改变、积水发亮、云压向镜头、窗内出现第二个观察者。

### 极繁拼贴

- 用一个最强的人类器官或身体局部作为视觉锚，例如眼睛、面部、手或胸腔。
- 周围以宗教纹样、电路、解剖、文字和屏幕填充，但保持一条从中心穿出的视线或轴线。
- 让色块密度呈“中心高、边缘可呼吸”或“四周高、中心留一块恐怖平静”的节奏。

### 肖像寓言

- 纯色平面背景、半身侧面或正面，轮廓像时装插画。
- 只做一次身份替换：面具嵌入脸、眼球变成天体、花束里长出器官。
- 服装保持完整、克制、可识别；异常越少，冲击越强。

## 动态语法

### 单镜头显灵

1. **观察：** 固定机位或极慢推进，先看清路灯、电线、树木、招牌和人物。
2. **异常进入：** 光点先出现，再放大成日轮或神性物体。
3. **空间响应：** 云层、倒影、路面和人物影子同时改变。
4. **停顿：** 允许 1–2 秒静止或轻微呼吸，让观众意识到自己也在观看。
5. **撤回：** 用雾、烟、黑场或声音骤停结束，不使用爆炸式连环变形。

### 五场景神话漫游

1. 以一个人物或窗内剪影建立观察者。
2. 横移或推进到城市全景，露出第二层尺度。
3. 切到更具体的地面物件，建立“同一个世界”。
4. 切入门槛，异象第一次越过日常边界。
5. 拉开到全局，城市、天体与人物同时可见。

每镜约 4–6 秒。镜头运动只做一件事：横移、推进、后退或静止。不要在一个镜头里同时摇、推、旋转并变形。

## 常见失败

| 失败 | 为什么失效 | 修正 |
| --- | --- | --- |
| 龙、眼睛、霓虹全堆在同一屏 | 没有主次，观者不知道看哪里 | 只保留一个主导异象，其余降为背景 |
| 城市像从未有人居住 | 缺少日常锚点 | 加入便利店灯箱、垃圾袋、空调外机或手机 |
| 所有元素都是同一种 3D 质感 | 拼贴变成游戏场景 | 保留硬边、线稿、纸噪和套色错位 |
| 人物摆出战斗姿态 | 观看变成征服 | 改为停下、仰望、背对或低头 |
| 无限走廊没有终点 | 空间巨大但没有事件 | 在轴线上放门、天体、龙口或强色块 |
| 视频一直 morph | 画面不稳定，语义被冲掉 | 让场景保持，使用慢镜头与单一显形 |
