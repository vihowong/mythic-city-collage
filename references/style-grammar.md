# 视觉语法：从色调到整体风格

## 样本读数

这套语法来自 43 张竖幅静态图的共同视觉表现。样本中 33 张接近 3:4，10 张接近 9:16；平均亮度偏低、颜色饱和度高、纯白面积极少。测量结果只用于校准方向，不是必须逐项复刻的公式：

- 平均明度约 0.37，深阴影区域约 41%，高光只有约 2%。
- 平均饱和度约 0.56，高饱和区域超过画面的一半。
- 暖色像素明显多于冷色像素，但不同作品的冷暖比例变化很大。
- 中等偏高的边缘密度说明画面细节丰富；真正决定秩序的是细节分区，而不是噪点数量。

整体上，它把传统版画的轮廓与空间感、迷幻海报的强色块、超现实舞台布景、时尚编辑式人物处理和局部数字材质压进同一张竖幅画面。

## 一句话风格

**用有限套版般的强色块、黑色轮廓和舞台式纵深，组织一个可读但不遵守正常物理规则的图像世界；细节必须成群，材质必须统一中有断点。**

它不像自然写生，也不像干净的三维幻想场景。画面首先是一张被设计出来的平面图形，然后才假装自己拥有空间。

## 一、色调：不是“颜色多”，而是色块有职权

### 三级明暗

1. **承重层。** 深钴蓝、近黑墨色、暗森林绿或暖黑棕，占据最大面积，建立天空、虚空、阴影或建筑块面。
2. **中间层。** 桃色皮肤、米白云、橄榄绿山林、赭石建筑和低饱和暖灰，让人物与景物有体积。
3. **事件层。** 朱砂红、橙红、电子蓝、金色高光出现面积较小，却决定视线落点和情绪峰值。

不要把所有色相都调到最高。高饱和本身不是风格，**高饱和区域占多数，但明度仍被压低，纯白被米色替代**，才是这套图像的味道。

### 冷暖不是固定象征

冷色通常提供宇宙深度、距离与精神性；暖色通常制造身体、热度和事件感。但参考图也会让暖色成为大面积规则背景，让冷色变成异常高光。稳定规律是：

- 冷暖控制要有压倒性的一方，不做五五开平衡。
- 冷暖交界落在主要轮廓、云团边缘、建筑体块或人物切面上。
- 同一色相既用于远景也用于皮肤、金属或字体，让不同空间被色彩重新缝合。

### 黑色有三种职责

- **结构黑：** 轮廓、发丝、阴影边缘、文字和边框。
- **虚空黑：** 星空、宇宙、深洞或未建模背景。
- **套版黑：** 让中间色变成平面图形，不追求真实光照。

不要用灰色雾霭把所有区域柔化。这里的黑通常是硬边、厚实、近乎印刷墨块；高光则集中、锐利、面积小。

### 推荐色角色

| 角色 | 观测到的主色 | 使用原则 |
| --- | --- | --- |
| 墨黑虚空 | `#070B05` | 15–30%，统一轮廓或制造无限空间 |
| 深海钴蓝 | `#12519D` / `#1A4068` | 20–40%，承担天空与远景 |
| 朱砂事件色 | `#E1401D` / `#8E4121` | 8–18%，放在视线旅程终点 |
| 桃色身体 | `#DDA17E` / `#EDC8B1` | 3–15%，人物、皮肤、象牙材质 |
| 米白停顿 | `#EDC8B1` / 偏暖高光 | 5–20%，云、纸面、空气出口 |
| 苔绿大地 | `#182510` / `#363D19` | 10–25%，山林、植被与重量 |
| 旧金/黄铜 | `#B28A45` | 0–6%，边框、金属或神圣等级 |
| 冷色亮边 | 青蓝或冷白 | 0–5%，只做节奏重音，不做霓虹泛光 |

每个画面最多让两种颜色争夺注意力，其余颜色只负责材料与体积。

### 颜色邻接结构

色相表只说明“有什么颜色”，不能说明风格是否成立。还要规定颜色怎么相接：

| 邻接结构 | 作用 | 示例判断 |
| --- | --- | --- |
| 深色包围事件色 | 让暖色像被秩序压住的裂缝 | 朱红只沿黑色或深钴蓝的一侧打开 |
| 中性色咬入冷色 | 用米白/暖灰打断大面积蓝黑 | 米白边缘有硬边和半调，不是发光泛白 |
| 冷色包围暖色 | 让暖色成为远处或内部事件 | 暖红被蓝黑与墨线夹住，面积不超过 8–20% |
| 中性色桥接冷暖 | 防止冷暖直接平均或脏灰 | 暖白/桃色或窄苔绿连接两块强色 |
| 金属/亮面切边 | 只提供极小面积高光 | 亮部不扩散成霓虹，仍由黑轮廓限制 |

验收时列出至少三组“颜色 A → 颜色 B”的邻接关系，并写出每组负责的结构。场景对象可以换，邻接关系不能一起消失。

## 二、构图：先设计视觉地形，再放内容

### 骨架一：孤立图腾

一个大主体占据中央或略偏中心，周围留出纯色场、云层或单一空间。人物可能横躺、悬浮、侧立或只露半身。冲击来自巨大的正负形关系，不来自背景堆料。

适合：单张封面、人物海报、强概念视觉。

关键判断：缩到缩略图时，主体轮廓仍能独立成立。

### 骨架二：轴线登临

底部人物或入口、中部阶梯/道路/地毯/透视带、顶部巨物或宇宙。画面常嵌套边框，并故意让仰望、俯瞰和平视同时存在。视觉流不能断，两侧高密细节只能拱卫轴线。

适合：神话全景、系列主视觉、纵深叙事。

关键判断：遮住中轴后，空间是否仍有清楚的进出关系；如果不能，问题通常在透视带或地平线，而不是元素数量。

### 骨架三：全景游行

画面从上到下或从左到右分成若干视觉带：宇宙、山体、城市、人群、地面。每个带都可包含独立小事件，但必须共享同一条地平线逻辑、同一套轮廓和同一色板。

适合：世界观海报、横版长图、音乐视觉。

关键判断：不要每层都使用相同细节密度。至少一条带应承担“安静承重”，用大色块让眼睛休息。

### 骨架四：正面祭坛

主体居中，放射线、双翼、对称边框或两侧回响形状围住中心。构图靠近宗教图像、舞台正面或专辑封面；高密度集中在中心，外围用重复秩序收束。

适合：仪式性人物、音乐封面、强符号构图。

关键判断：对称不等于镜像复制。两侧应有热度和细节差异，否则会变成机械贴图。

### 骨架五：超近景切片

脸、眼睛、手、胸腔、面具局部或物件占满画面，以斜切、遮挡和强色背景制造冲击。背景可能只有一种钴蓝或黑色，细节集中在主体表面。

适合：人物特写、编辑视觉、悬疑或欲望题材。

关键判断：不要让滤镜制造“复杂”，应由切口、视线、手部动作或材质边界完成张力。

### 骨架六：框中世界

门框、窗、画框、屏幕或舞台口围出第二空间。外框负责秩序和距离，内部负责深渊、宇宙或另一个世界。两层空间可拥有不同透视，但不能拥有不同材质语言。

适合：门户、时间折叠、观看关系。

关键判断：边框是“图像装置”，不是默认装饰。只有当它能控制观看距离或建立第二现实时才使用。

### 形状层级

一张图通常由一个巨大形、若干中形和许多小形组成。最稳的比例不是固定数值，而是明显的**尺度跳变**：

- 一个占画面 25–60% 的大形，负责远读。
- 两到四组中形，负责空间层级和叙事。
- 只在局部密集出现的小形，负责近看信息。

所有小形同样清楚，会让大形消失；所有大形同样巨大，会让画面失去尺度。远看的轮廓与近看的细节必须同时存在，但观看顺序不能反过来。

### 细节地形

参考图的细节并非均匀撒满。常见分布是：

- 下部或前景更密，形成“地面证据”；
- 中央轴或主体边缘更密，形成视线隧道；
- 边缘装饰带周期性重复，像文本栏或画框；
- 天空、虚空和纯色平涂负责大面积停顿。

不要强制把高细节放在固定位置。先把画面画成三到五块“地形”，再判断哪一块需要密度。高密区域应形成可命名的团块：云团、人群、建筑群、山林、文字带、面部结构或机械结构。

## 三、线、形与明暗：像印刷，不像渲染

### 轮廓

外轮廓必须坚定，内部轮廓可以因细节增加而变化。人物、面孔、动物和主体建筑通常用黑色硬线；云、波浪、衣褶和肌肉则用细线、排线或钩状线组合。无论材质如何变化，轮廓粗细关系要一致。

### 阴影

阴影多为硬边色块或半调层，不以真实衰减的柔和渐变塑形。面部可有三到四档明暗，建筑可有明确的黑色面与彩色面，云层可以有巨大的亮暗团块。

### 表面

统一表面来自三种重复：

1. 同一种黑色轮廓；
2. 同一种有限套版色关系；
3. 同一种纸面噪声或半调颗粒。

颗粒应出现在整张图的连续表面上，而不是只覆盖“复古部分”。如果主体像干净数字渲染，背景像旧纸，二者会像两张图叠在一起。

## 四、细节：密度必须有语法

### 三个尺度

- **宏观：** 剪影、地平线、框边、中心轴。
- **中观：** 云、山、建筑、人群、花束、面部结构、屏幕块。
- **微观：** 排线、文字、网点、金属亮点、叶片和鳞片。

宏观必须在一秒内读出；中观在数秒内形成叙事；微观只在近看时提供文化层和材料触感。

### 细节岛的规则

- 每个高密区只解释一件事：包围、目睹、吞噬、上升、坠落、交换、复制或封锁。
- 细节在边缘应收束成清楚的轮廓，不能溶成一团随机纹理。
- 同一图案必须有尺度变化。等大重复三次以上会变成壁纸，大小差异和不完整裁切才会形成世界。
- 文字优先作为节奏带、纹理柱或叙事框；不要堆无意义小字来制造“复杂感”。
- 留白不是未完成。大色场、黑空、云海都是让高密细节有效的前提。

### 细节不是越多越好

样本的高边缘密度来自可读图形的大量相邻，而不是随机噪声。遇到“丰富但不好看”，先检查：

1. 高密区域是否不超过三到四个？
2. 每个区域是否有明确边界？
3. 最亮和最暗的点是否集中在事件位置？
4. 把细节全部变成纯灰色后，是否仍有主形与轴线？

## 五、材质：统一表面，局部断裂

### 基础材质

默认基底是“传统印刷与当代图形设计的混合”：平涂色块、黑色套版、细线刻纹、纸纤维、半调网点和轻微套色错位。它不属于某一种真实纸张，而是一个稳定的图像表面。

### 可出现的材质事件

- 写实摄影硬边切片；
- 旧版画或解剖图的线刻；
- 金属、镜面、珠宝或铬合金高光；
- 像素、屏幕界面、打字机式字体；
- 平面时尚插画或服装色块。

材质事件应少而有含义。一个画面通常只需要一个主导断裂；其余部分服从基础印刷表面。

### 统一异质材料

不要给每个素材单独加一种滤镜。用以下方式把它们压进同一世界：

- 同一黑色轮廓穿过不同材质；
- 让同一朱砂红既出现在云、衣服，也出现在数字界面；
- 用相同硬边遮挡和裁切方式；
- 让全局颗粒覆盖所有材料；
- 让光源逻辑部分一致、关键位置故意冲突。

## 六、可替换的视觉职责

不要把下列物件当成必选清单。它们对应的是画面职能，任何主题都可以用自己的形象完成。

| 视觉职责 | 可替换形式 | 判断标准 |
| --- | --- | --- |
| 承重主体 | 人物、动物、面孔、建筑、抽象体 | 是否有大而清楚的轮廓 |
| 观看尺度 | 小人物、背影、眼睛、窗口、观众群 | 是否让观众获得距离与尺度 |
| 空间门槛 | 道路、门框、阶梯、台面、水面、屏幕 | 是否真正连接两个空间 |
| 事件色块 | 天体、火、花、服装、霓虹块、装置 | 是否只承担一次强视觉事件 |
| 秩序边缘 | 花纹、文字、网格、重复符号、画框 | 是否帮助收束而非抢焦点 |
| 材质断点 | 镜面、照片、像素、金属、纸片 | 是否让世界规则发生一次可见变化 |

先写职责，再从主题中寻找对应形象。若形象只提供装饰、不改变空间或观看关系，降为纹理或删除。

## 七、六种作品类型的气质差异

### 孤立型与祭坛型

更接近杂志封面和现代平面设计。色块面积大，边缘干净，主体像雕塑或剪影。不要用全景细节填满背景。

### 轴线型与框中型

更接近舞台布景和神话图解。重点是纵深、门槛、层级和一条能走入画面的路径。透视可以错，但入口不能含糊。

### 全景型与超近景型

更接近旧式印刷叙事和超现实编辑插画。前者需要横向分区与群体细节，后者需要强裁切、视线和局部材质密度。两者都不应变成无中心的素材仓库。

## 八、整体风格判断

看到画面时，依次问：

1. 忽略人物、城市、建筑和故事名称后，色块面积与方向结构是否仍成立？
2. 颜色是否形成承重、过渡、事件、停顿四级，并存在清楚的邻接关系？
3. 灰度下是否仍有明确的主次与高光控制？
4. 细节是否有起伏，还是全图同一密度？
5. 油墨边缘、半调、纸噪、套色错位与材料断点是否共享一个图像表面？

前两项是主验收：色彩搭配结构和图像质感。空间、场景和对象只负责承载它们。风格不是纹理过滤器，也不是某组题材，而是色块、表面和材料的组织方式。

## 九、常见漂移

| 漂移 | 视觉症状 | 修正 |
| --- | --- | --- |
| 元素仓库 | 多个主体同等巨大，靠名词解释画面 | 选一个承重形，其他降成中形或纹理 |
| 彩虹化 | 每个区域都高饱和，纯白和黑色都很多 | 减少色相数量，压低明度，集中事件色 |
| 三维游戏感 | 平滑体积、统一光照、边缘全都清楚 | 改为硬色块、黑轮廓、局部线刻与套色错位 |
| 复古贴纸化 | 图形都浮在纸面上，没有空间关系 | 建立地平线、遮挡和一条入口 |
| 全图噪声 | 纹理丰富但缩略图无主形 | 把纹理限定在表面层，先重建大色块 |
| 过度堆字 | 文字比图像更像主体 | 只保留一种字体和一条文字密度带 |
| 符号拼盘 | 去掉物件名称后没有任何视觉命题 | 回到色调、空间、主轮廓和细节层级 |
| 统一滤镜 | 每部分质地相同，拼贴关系消失 | 保留一个基础印刷表面，只给一处材质断裂 |
