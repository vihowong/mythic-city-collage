# 神话城市拼贴 — 共享术语

| 术语 | 本体系中的定义 | 关键区别 |
| --- | --- | --- |
| 视觉命题 | 一个能脱离具体象征物名称成立、可由构图和色调验证的画面张力 | 不是题材描述，也不是“复古、迷幻”等风格标签 |
| 压缩色调 | 收窄色相、明度和高光范围，形成有限套版式面积关系 | 不是所有颜色同时最饱和，也不是灰色电影感 |
| 承重色 | 大面积建立天空、虚空、阴影、山林或建筑结构的深色/暗饱和色 | 不等于普通背景色 |
| 事件色 | 小面积但高对比，用来标记唯一视觉峰值或空间操作的颜色 | 不必固定为红色，也不能多处同级竞争 |
| 停顿色 | 米白、桃色、暖灰或低密云海形成的观看休息区 | 不是纯白空白 |
| 主轮廓 | 缩略图下首先识别的大形、主面孔或终止轴线的大体量 | 不是最亮或细节最多的地方 |
| 舞台空间 | 通过入口、地平线、遮挡、边框和层级形成、允许透视冲突但观看路径可读的空间 | 不是写实透视，也不是纯平面拼贴 |
| 细节岛 | 二至四个有边界、可命名并承担叙事职责的高密区域 | 不是全图随机碎屑 |
| 密度地形 | 低密、高密与过渡区域的面积安排和阅读顺序 | 不是单纯增加噪点 |
| 印刷表面 | 黑轮廓、平涂阴影、套色偏移、半调、纸噪和硬边裁切形成的连续基底 | 不是只作用于背景的复古滤镜 |
| 材质断点 | 少量侵入基础表面的摄影、金属、屏幕、字体或像素事件 | 不是每个素材各用一种滤镜 |
| 视觉职责 | 承重主体、观看尺度、空间门槛、事件色块、秩序边缘或材质断点的功能 | 不是物件名称或固定象征含义 |
| 构图骨架 | 孤立图腾、轴线登临、全景游行、正面祭坛、超近景切片或框中世界 | 不是题材，也不是装饰风格 |
| 观看锚点 | 矛盾空间中的连续中轴、地平线、框边、遮挡或贯穿色块 | 不要求真实透视，但必须让观众重新定位 |

## 使用规则

- 先写视觉职责，再替换具体形象。
- 术语用于做取舍，不用于给画面贴标签。
- “细节丰富”“高饱和”“超现实”缺少面积、边界或动作时，不能作为完成标准。
