# kiuzyx 视觉语法共享术语

| 术语 | 本技能中的定义 | 关键区别 |
| --- | --- | --- |
| 色彩面积结构 | 颜色按大面积承重、次级色场、局中事件和暖中性停顿分配面积 | 不是列出用了哪些色相 |
| 颜色邻接 | 两种颜色直接相接的位置、面积顺序和承担的结构 | 不是色板里同时出现 |
| 深色承重 | 深蓝、近黑、暗绿占据画面主要重量 | 不等于只是暗背景 |
| 暖中性停顿 | 米白、暖棕、肤色和灰褐为画面提供呼吸和中间层 | 不是纯白留白 |
| 事件色 | 朱红、橙色等只占小面积、用来标记视觉峰值的颜色 | 不是大面积主色 |
| 正交场域 | 由门窗、墙线、桌沿、道路和地平线形成的横竖舞台 | 不要求真实透视 |
| 负形场 | 有颜色和颗粒、但信息密度低的大面积空间 | 不是空白未完成 |
| 细节岛 | 有明确边界和职责的局部高密区域 | 不是全图均匀细节 |
| 多尺度微颗粒 | 细纸噪、中点阵/抖动和较大压缩/刷痕共同覆盖整图 | 不是单一噪声滤镜 |
| 清晰硬边 | 在微颗粒下仍能读出的建筑、人物和色块边界 | 不等于完全无纹理矢量 |
| 场景独立性 | 忽略人物、房间、城市等名称后，仍能辨认色彩结构和图像质感 | 不是要求画面抽象 |
| 安静场域 | 负形大、边缘密度低、人物小的正交舞台 | 不等于没有事件 |
| 极繁全景 | 用黑空、云海、城市和神兽组织多密度带 | 不等于全屏随机元素 |

## 使用规则

- 先写色彩职责和邻接，再考虑场景。
- 先写结构模式和负形，再增加细节。
- 图像质感必须同时看边缘、暗部、高光、微颗粒及纹理尺度。
- 成图验收通过前，不把提示词或视觉分析视为完成。
