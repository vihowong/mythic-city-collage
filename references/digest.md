# 神话城市拼贴 — 视觉语法精华

> 本文只呈现通过三重验证与边界测试的内容。它不是 43 张图的作品摘要，而是一套可迁移的图像组织方法。图片生成与成图验收是实际交付依据；素材作者与授权追溯不属于本技能的操作门槛。

## 这套视觉真正统一在哪里

这组图表面上混合了人物、面孔、城市、山水、宇宙、版画、摄影、金属和文字，但把这些题材拆掉以后，仍然能辨认出同一种图像组织方式：大面积压缩色调承担重量，少量事件色标记异常，舞台式空间把观看者放进一个不完全遵守物理规则的世界，细节以密度岛出现，最终由统一的黑色轮廓、平涂和印刷颗粒把不同材料重新缝合。

所以，风格不是“龙、眼睛、门、棋盘”的集合。一个画面即使完全没有这些物件，只要保留色调分工、强轮廓、空间层级、受控密度和材质断裂，仍然属于这套视觉；反过来，把所有象征物都堆进去，如果没有主轮廓和空间关系，也只是一张神话素材拼贴。

最重要的验收转向是：**不要用场景识别来判断风格成立。** 色块有多大、什么颜色挨着什么、冷暖在何处冲突、明度由谁承重、半调/纸噪/套色错位怎样分布、哪种材料在何处断裂，这些才决定画面质感。人物、城市、黑日或任何故事都是可替换载体。

## 一、先写视觉命题，再找形象

创作应从一条不依赖具体物件名称的张力开始。比如：

- 熟悉的日常表面与不可见的控制层同时存在。
- 完整、克制的身份内部出现无法维持的冲动。
- 观看者以为自己正在发现宇宙，实际却正被宇宙发现。
- 一种秩序覆盖另一种秩序，但覆盖的边缘正在泄露。

命题通过后，才可以寻找载体。载体先承担视觉职责：谁是大形，谁提供观看尺度，谁是空间门槛，谁只承担一个事件色，谁负责边缘秩序。无法说明职责的形象，通常只适合做纹理或删除。

这一步可以用一个简单盲测验证：删掉所有象征物的名称后，画面是否仍然让你感到尺度压迫、仪式、窥视、穿入或失控。如果只有名词能解释意义，命题还没有成立。

## 二、色调是面积制度，不是色相数量

43 张样本的平均明度约为 0.37，深阴影区域约 41%，高光只有约 2%，同时平均饱和度约为 0.56。这个组合说明图像并非简单“颜色越多越亮越有风格”，而是偏暗的大色块承重、强烈但受控的中明度色彩、极少的锐利高光。

最稳定的四种颜色职责是：

1. **承重色**：深钴蓝、墨黑、暗绿或暖黑，建立天空、虚空、阴影和建筑重量。
2. **过渡色**：桃色、赭石、暖灰、橄榄绿，给人物、材质和景物体积。
3. **事件色**：朱红、橙红、强青或金属亮部，标记唯一视觉峰值。
4. **停顿色**：米白、暖象牙和低密云海，给复杂细节提供呼吸。

高饱和不是把每个色相都推到最大值。纯白高光越多，画面越容易变成泛光海报；事件色越多，观众越不知道该看哪里。每张图通常只让一两个颜色争夺注意力，其余颜色负责结构和体积。

灰度测试是最直接的检验：去掉颜色以后，画面仍应保留大面积深色、中等体积和少量锐亮区域。如果只剩平均灰亮，说明颜色在代替构图，而不是支持构图。

## 三、构图先于题材：六种舞台骨架

样本不是只有一条纵向轴线。它可以分成六种稳定的视觉地形：

| 骨架 | 主要体验 | 常见做法 |
| --- | --- | --- |
| 孤立图腾 | 压缩、悬浮、单点冲击 | 一个大主体占据巨大负形场 |
| 轴线登临 | 朝圣、进入、尺度递进 | 底部入口经中央通道走向顶部大形 |
| 全景游行 | 世界观、漫游、文明层叠 | 宇宙、山体、城市、人群形成密度带 |
| 正面祭坛 | 仪式、权威、强烈对称 | 中央主体、放射线、边框或双翼 |
| 超近景切片 | 恐惧、欲望、窥视 | 脸、眼、手或物件占满画面并被斜切 |
| 框中世界 | 第二现实、观看距离 | 门框、画框、屏幕或舞台口套住另一层空间 |

每种骨架都必须先有一个 200px 缩略图下可识别的主轮廓或主空间轴。不需要所有东西简单，只需要第一识别关系简单。复杂感来自同一骨架内部的层级，不来自同时使用多个竞争骨架。

样本全部是竖幅，因此这六种骨架只能作为竖幅默认。横向、方形和网页横幅必须重新设计水平分区，不能把竖图拉宽或裁切后声称适配完成。

→ 深入：[构图骨架能力卡](capabilities/composition-skeleton.md)

## 四、空间像舞台，不像自然风景

这套视觉里的“空间感”不是写实相机的景深，而是舞台布景、宗教立面、剖面图和海报透视的混合。一个稳定空间通常包含：

- 一个明确入口；
- 二至四层地平线、遮挡或边框；
- 一个终止轴线的大形；
- 一次尺度、重力或透视矛盾；
- 至少一个让观众重新定位的观看锚点。

锚点可以是连续中轴、统一地平线、框边、前景遮挡或贯穿多个空间的色带。没有锚点时，矛盾透视会变成不同素材浮在同一张纸上；锚点过强时，又会让超现实被压回普通透视。目标是让“不可能”局部发生，让世界整体仍能被读懂。

→ 深入：[舞台空间能力卡](capabilities/stage-space.md)

## 五、细节要有地形，而不是噪声

极简图和极繁图都能属于同一体系。前者用主体内部结构制造第二层细节；后者用城市、云山、人群、面部或文字带形成密集团块。共同点是：高密信息有边界、有职责，并且周围一定有低密承重区。

一个实用起点是二至四个细节岛：

- 第一岛围绕视觉事件；
- 第二岛提供地面或生活证据；
- 第三岛建立边缘秩序或文字节奏；
- 其余区域保留为平涂、黑空、云海或大色块。

这不是硬性数量规律，而是帮助先画密度地形。文字应优先做成单一边带、纹理柱或边框，不能靠大量不可读小字制造复杂。缩略图测试失败时，应删减细节，而不是提高对比或增加噪声。

→ 深入：[细节密度能力卡](capabilities/detail-density.md)

## 六、材质统一中有一次断裂

这套图像看起来是拼贴，因为它不把世界磨成同一种光滑渲染。人物可能像版画，云可能像硬边照片，金属可能像数字渲染，文字像印刷边带。但它们又属于同一个世界，因为共同使用：

- 黑色或深墨轮廓；
- 平涂或套版式阴影；
- 同一组钴蓝、朱红、米白与墨黑关系；
- 连续覆盖所有材料的半调、纸噪或套色错位。

典型结构是“一个连续印刷表面 + 一个主导材质断点”。断点应回答视觉命题，比如镜面金属让人物从被观看者变成反射装置，数字像素揭示第二现实，摄影切片证明一个空间曾真实存在。断点过多，每种素材拥有自己的滤镜，拼贴就会退化成一堆贴纸。

样本并不证明永远只能有一个材质断点；更准确的说法是只能有一个同级主断点，其他材料必须降为纹理、边带或小面积回响。

→ 深入：[材质表面能力卡](capabilities/material-surface.md)

## 七、从设计决策到提示词

可用的提示词不能只写“暗色、迷幻、超现实、复古版画、龙、城市”。它应该是前面设计决策的编译结果：

1. 画幅与用途；
2. 视觉命题；
3. 构图骨架、主轮廓与入口；
4. 前中后空间和透视矛盾；
5. 承重色、过渡色、事件色、停顿色；
6. 二至四个细节岛；
7. 基础印刷表面与主导材质断点；
8. 具体形象及其职责；
9. 针对本次高风险漂移的负面约束。

形象放在后半段，是为了防止提示词过早锁定素材。负面约束也应针对本次问题，例如“多焦点、平均彩虹、全图均匀密度、塑料三维”，而不是复制一份万能禁词表。

→ 深入：[提示词编译能力卡](capabilities/prompt-compiler.md)

## 八、修复顺序：结构、灰度、密度、材质

画面“很丰富但不好看”时，先不要加纹理。应依次检查：

1. 200px 缩略图是否有主轮廓或轴线；
2. 灰度是否仍有承重、过渡、事件三级；
3. 细节是否成岛，是否有足够低密区；
4. 黑轮廓、颗粒和材质断点是否共享同一表面；
5. 删除象征物名称后，形式张力是否仍然成立。

只修最上游的失败层。主轮廓失败时，调色和加纹理只会放大混乱；色彩失效时，增加更多细节也会让问题更贵。

→ 深入：[诊断修复能力卡](capabilities/diagnose-repair.md)

## 九、系列要固定视觉表面，不要复制构图

系列连续性的核心不是每张都出现同一个物件，而是共享同一套视觉制度。固定项通常包括：

- 色调角色和面积关系；
- 黑轮廓、阴影与全局颗粒；
- 一个主构图骨架或两个受控变体；
- 一个主导材质断点规则；
- 文字和边缘秩序的语言。

可变项包括主体、裁切、环境、剧情事件和密度岛的题材。最简单的一套三连作是：第一张以孤立主体锁定视觉表面；第二张把同一主体放进轴线舞台；第三张展开全景，使主体成为尺度关系的一部分。每张只推进一个新的空间职责。

→ 深入：[系列连续性能力卡](capabilities/series-continuity.md)

## 十个最容易出现的陷阱

1. **元素清单化。** 去掉物件的名字后，没有任何视觉命题。
2. **平均彩色。** 每种色相都同样饱和、同样重要，最后没有事件色。
3. **高光泛滥。** 大量纯白和泛光把深色承重与有限套版感全部抹掉。
4. **全图同密度。** 缩略图只剩噪声，主轮廓、入口和留白消失。
5. **多个同级焦点。** 所有主体都巨大、都发光、都清楚。
6. **干净三维化。** 所有材质共享平滑塑料光照，拼贴断点消失。
7. **贴纸化。** 每个素材有自己的滤镜、投影和轮廓，彼此没有遮挡与空间关系。
8. **完美镜像。** 对称祭坛被逐像素复制，失去局部生命与第二层信息。
9. **边框代替空间。** 去掉金色和花纹后，中心画面完全没有入口和深度。
10. **竖幅规律强行横推。** 把 3:4 构图直接裁成 16:9，导致两侧空洞和轴线断裂。

## 这套蒸馏必须保留的局限

- 本文规则是从视觉现象推导的工作语法，不写成作者原意；素材作者与授权追溯不属于本次验收范围。
- 43 张静态图全部是竖幅，横向、方形和排版型载体尚未得到视觉样本支持。
- 颜色和密度统计只能说明表面分布，不能替代眼动研究、印刷测试和真实观看反馈。
- 只有两段视频样本，动态与声音结论不能上升为完整电影语言。
- 二至四个细节岛、35–55% 承重面积等数字是设计起点，不是跨项目定律。
- 过度抽象成公式可能失去题材的具体文化与时代关系；调用时必须重新为每个主题寻找职责。

## 关键术语速查

| 术语 | 用法 |
| --- | --- |
| 视觉命题 | 删除具体象征物名称后仍成立的形式张力 |
| 承重色 | 大面积建立空间重量与结构的颜色 |
| 事件色 | 小面积、标记唯一视觉峰值的颜色 |
| 停顿色 | 提供呼吸、观看距离和材料温度的暖中性区域 |
| 主轮廓 | 200px 缩略图下首先识别的大形或轴线 |
| 舞台空间 | 由入口、遮挡、地平线和边框建立的可进入空间 |
| 细节岛 | 有边界、有职责的高密信息团块 |
| 印刷表面 | 黑轮廓、平涂、半调、纸噪和套色偏移形成的连续基底 |
| 材质断点 | 少量侵入基础表面的摄影、金属、像素或字体事件 |
| 观看锚点 | 让矛盾透视仍可被定位的中轴、边框、地平线或色带 |

完整词典见 [glossary.md](glossary.md)。

## 如果只带走三句话

1. 这套风格首先是一张被设计的平面图形，然后才假装拥有空间。
2. 远看靠主轮廓和色调层级，近看靠细节岛和材质断点。
3. 具体符号可以替换，色调职责、空间组织、密度节奏和统一表面不能丢。
