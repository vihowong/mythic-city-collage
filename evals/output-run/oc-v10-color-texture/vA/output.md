# 色彩结构与图像质量验收方案

## 色彩面积

- 深钴蓝：28%，作为冷色承重场。
- 近黑：27%，建立阴影、深空和边界。
- 暖米白：24%，作为低频停顿和纸面呼吸区。
- 朱红：9%，只做单一事件带。
- 暖棕与暗绿：12%，承担过渡和桥接。

## 颜色邻接

1. 米白咬入深钴蓝，边界由硬线控制。
2. 朱红切过近黑大场，形成唯一的暖色事件。
3. 暖棕桥接蓝黑与米白，避免冷暖直接变成平均彩虹。

## 构图

使用安静正交场域：一条竖向结构线和一条底线组织画面，至少 40% 保持低频负形。画面不依赖具体人物、房间或故事；**场景**只是色块和材质的可替换承载。

## 图像质量

- 轮廓清楚，色块硬边。
- 微颗粒覆盖整张图，包含细纸噪、中尺度抖动/网点、较大压缩块三种尺度。
- 暗部保留蓝黑层次，不压成死黑。
- 高光极小，不放泛光。
- 金属或亮面只作为不超过 2% 的材料断点。

## 验收

缩略图应能读出色块面积和结构轴；灰度后仍有蓝黑承重、米白停顿和朱红事件；忽略所有场景后，色彩结构与图像质感仍成立。
