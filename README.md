# 神话城市拼贴

一个结合 `@kiuzyx` 近期 27 张作品、现有 43 张历史作品与 2 段动态研究蒸馏出的 Codex 技能。它不从象征物或场景清单出发，而是以**色彩搭配结构、构图模式、明暗面积、微颗粒与图像复制质感**为核心，把空间、人物和故事视为可替换承载物。

`v1.4.0` 加入近期作品对照、安静场域/极繁全景双模式、多尺度微颗粒、19 个输出用例和新的实际成图验收。`v1.3.0` 已建立“去场景测试”和实际生成图验收，`v1.2.0` 完成 cangjie-skill 的五路提取、三重验证和九张能力卡。

图片生成和成图验收是技能的必要交付环节；素材作者与授权追溯不作为操作门槛。

验收重点不是画面出现了什么场景或对象，而是**色彩的搭配结构**与**图片质感风格**：色块面积、冷暖邻近、明度层级、印刷颗粒、套色错位、纸张触感和局部材质断裂。

## 能做什么

- 用承重色、过渡色、事件色、停顿色和颜色邻接关系组织画面
- 在安静正交场域与极繁全景之间选择构图模式
- 用黑轮廓、粗糙油墨边界、半调、纸噪、套色错位与材料断点形成统一质感
- 让构图骨架组织色块和密度，而不是要求固定场景或象征物
- 以“去场景测试”检查忽略人物、城市、建筑和故事后，色彩结构与表面质感是否仍成立
- 将高密细节组织成“岛”，避免均匀噪点与素材仓库
- 生成孤立图腾、轴线登临、全景游行、正面祭坛、超近景切片和框中世界提示词
- 设计 6–20 秒单镜头显形或 24–32 秒多场景漫游
- 按可量化标准修复“元素拼贴、彩虹化、三维游戏感、贴纸化、整体失焦”等问题
- 按需加载视觉命题、构图、色调、空间、细节、材质、提示词、诊断或系列能力卡
- 用缩略图、灰度、去名词、颗粒连续性和缺输入场景进行边界测试
- 调用实际图像生成器并对成图进行缩略图、灰度、色调、细节和材质验收

## 安装

把整个 `mythic-city-collage` 文件夹放入 Codex 技能目录：

```text
$CODEX_HOME/skills/mythic-city-collage
```

未设置 `CODEX_HOME` 时，通常使用：

```text
~/.codex/skills/mythic-city-collage
```

## 调用示例

```text
用 $mythic-city-collage 设计一张不依赖具体场景的海报：重点是钴蓝、墨黑、米白与朱红的面积和邻接关系，以及丝网印刷的半调、套色错位和纸纤维质感。生成成图后按去场景测试验收。
```

```text
用 $mythic-city-collage 检查这张图：忽略人物和建筑后，色彩结构是否仍有主次，粗糙油墨边界、干燥刷痕、半调尺度和金属断点是否统一，并给出最小修复。
```

## 文件

- `references/production-recipes.md`：视觉命题、五类图像配方、改图、系列和视频模板
- `references/quality-rubric.md`：静态/动态评分、五种盲测与按层级修复方法
- `references/capability-index.md`：9 个能力的完整意图/关键词路由
- `references/capabilities/`：按需加载的 R/I/A1/A2/E/B 深层能力卡
- `references/cheatsheet.md`：九条决策规则速查
- `references/glossary.md`：共享视觉术语
- `references/overview.md`：蒸馏来源、骨架、批判与边界
- `references/digest.md`：面向读者的视觉语法精华
- `references/visual-acceptance.md`：提示词、实际成图、评分与修订记录
- `references/visual-acceptance/`：近期作品风格的最终提示词、实际成图与修订版本
- `test-prompts.json`：darwin 兼容的触发与边界用例
- `test-results.md`：fallback 自测、输出断言与未完成项

## 边界

这个仓库发布的是提炼后的方法，不包含原始参考图片或视频。它不用于复制某位创作者的既有作品，也不用于普通旅行摄影、常规霓虹赛博朋克或只做素材摘要的请求。
