# 神话城市拼贴

一个从 43 张竖幅视觉作品与 2 段动态研究中蒸馏出的 Codex 技能。它把“普通城市被神话、拼贴和异象侵入”的视觉规律转成可执行的创作流程、图像提示词、短视频分镜与质量验收标准。

## 能做什么

- 建立图像或视频的视觉概念与艺术指导
- 生成一致的神话全景、日常显灵、极繁拼贴和肖像寓言提示词
- 设计 6–20 秒单镜头显灵或 24–32 秒多场景漫游
- 规划三连作或系列作品的固定项、可变项和连续性
- 按可量化标准修复“太像普通赛博朋克、太满、太光滑、没有叙事”等问题

## 安装

把整个 `mythic-city-collage` 文件夹放入 Codex 技能目录：

```text
$CODEX_HOME/skills/mythic-city-collage
```

未设置 `CODEX_HOME` 时，通常使用：

```text
~/.codex/skills/mythic-city-collage
```

## 调用示例

```text
用 $mythic-city-collage 把“凌晨两点便利店门口的等待”做成一套三连主视觉。
```

```text
用 $mythic-city-collage 写一个 12 秒竖屏视频方案：雨后的高架桥、一个抽烟的人、逐渐升起的巨大白日前，以及水洼里的第二层城市。
```

## 文件

- `SKILL.md`：入口、工作流、输出契约与硬性质量闸门
- `references/style-grammar.md`：构图、色彩、材质、符号与动态语法
- `references/production-recipes.md`：图像提示词、视频镜头、声音和交付模板
- `references/quality-rubric.md`：评分表与快速修复方法

## 边界

这个仓库发布的是提炼后的方法，不包含原始参考图片或视频。它不用于复制某位创作者的既有作品，也不用于普通旅行摄影、常规霓虹赛博朋克或只做素材摘要的请求。
